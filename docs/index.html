Segmenting a hand in a depth frame

Move the generated hand, change its depth, and adjust the segmentation cutoff. The viewer shows a depth image, a connected region and its pixel centroid.

New illustrative browser demo · Procedural hand-shaped depth data and a simple connected-component segmenter. It is not a port of the recovered MATLAB/MEX tracker and uses no PMD camera.

The source algorithm uses seed selection and 3D distance constraints; this separate demo uses a simpler 4-connected depth threshold to make one segmentation step visible. The 160 × 120 generated frame contains one hand shape over a flat background. No tracking accuracy, PMD compatibility or real-camera performance is claimed.
